Durable execution

Running an agent so that a crash, a timeout or a pause for review never loses work: every step is checkpointed, and the run resumes where it stopped.

3 sourcesUpdated 17 Sep 2026Language EnglishConfidence high
Open full pageDownload Markdown

Durable execution treats an agent run as a sequence of recorded steps rather than one long function call.1 The inputs and outputs of each step are written to a checkpoint store before the next step starts, so a failure costs one step instead of the whole run.2

In LangGraph the checkpointer stores graph state per thread; resuming replays nothing that already succeeded.3 The same mechanism makes human review practical: a run can wait hours for approval and continue unchanged.
